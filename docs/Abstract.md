# Abstract

The rapid expansion of university campuses increases electricity demand, operating cost and pressure on local power grids. Conventional building-energy management systems usually centralise high-frequency smart-meter readings, weather information and occupancy schedules to train one forecasting model. This approach can expose occupant behaviour, increase network traffic and perform poorly when buildings have different usage patterns. New facilities also lack enough historical data to train accurate models.

This project proposes a privacy-preserving, federated cloud framework for short-term energy-load forecasting and demand-side optimisation across multiple campus buildings. Each building uses an edge node to clean telemetry, train a lightweight CNN-LSTM/GRU forecasting model and protect its model update with Gaussian differential privacy and pairwise secure aggregation. Raw operational data remains at the building. Protected updates are transmitted through AWS IoT Core, validated by AWS Lambda and aggregated by Amazon SageMaker using data-quality-aware federated averaging. The resulting global model is stored in Amazon S3 and redistributed for local fine-tuning, including cold-start buildings.

The global demand forecast feeds a serverless optimisation function that schedules flexible loads such as HVAC pre-cooling, EV charging and battery dispatch according to time-of-use tariffs. Amazon DynamoDB stores participant metadata and tariff plans; Amazon Cognito and IAM secure access; API Gateway exposes dashboard APIs; CloudWatch and SNS provide monitoring and alerts; and Amazon QuickSight supports executive reporting. The target outcome is a scalable platform that reduces peak demand by at least 20% while preserving data privacy and improving operational visibility.
