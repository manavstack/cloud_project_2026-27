# Architecture Diagrams

The two mandatory Phase I diagrams are provided as editable SVG source files:

- AWS_Architecture.svg - AWS service interactions, data flow, storage, processing, monitoring and authenticated API access.
- System_Architecture.svg - end-to-end workflow from sensors through edge learning, aggregation, optimisation, dashboard and building control.

SVG is intentionally used so labels and service placements can be revised without quality loss before final report export.
